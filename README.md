# 🤖 NEXA – AI Voice Assistant

NEXA is a futuristic AI voice assistant inspired by JARVIS.
It can control your PC using voice commands.

## ✨ Features
- Voice-controlled PC operations
- Open apps (Chrome, Explorer, YouTube, Google)
- Type anywhere using voice
- System shutdown & control
- Custom futuristic UI
- Auto-start on Windows boot
